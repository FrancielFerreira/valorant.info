# Spec

## Stack

- React 18.
- Vite.
- React Router DOM.
- Tailwind CSS.
- Valorant API publica.

## Rotas

- `/`: home.
- `/agentes`: agentes jogaveis.
- `/mapas`: mapas.
- `/modos`: modos de jogo.
- `/armas`: armas.

## Design

- Tema escuro tatico.
- Acento principal vermelho Valorant.
- Tipografia de display para titulos.
- Cards com bordas, gradientes e hover states.
- Layout responsivo mobile-first.

## Dados

Os dados sao carregados diretamente da Valorant API em `pt-BR`. Uma camada de cache serverless pode ser adicionada futuramente se o projeto crescer.
